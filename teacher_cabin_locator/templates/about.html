ABOUT THE PROJECT

Less time searching.
More time where you need to be.

GNITS Teacher Cabin Locator is a campus directory concept designed to help students and visitors find faculty cabin and building details in one place.

⌕

Search quickly

Search faculty by full or partial name, department or designation. Browse building locations separately.

⌂

Know where to go

Faculty records can show the building, floor, cabin/room number and an optional saved map link.

♜

Keep details updated

An authorised Creator can add, edit and remove records so the directory can be maintained over time.

Important information

  • Faculty and building details must be entered and verified by the project team.
  • A map link opens a saved location; this website does not use a live Google Maps API or indoor navigation.
  • The website does not show whether a teacher is currently in their cabin.
  • Please report outdated details to the department or project administrator.
